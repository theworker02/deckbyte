# deckbyte

Deck URLs and byte query parts with stable normalization.

**Site:** https://theworker02.github.io/deckbyte/

## Install / run

```bash
git clone https://github.com/theworker02/deckbyte.git
cd deckbyte
node src/cli.js
node --test
```
